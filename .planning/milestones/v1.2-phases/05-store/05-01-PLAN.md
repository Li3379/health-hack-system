## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client Store ↔ Public REST API (`GET /api/metrics/metadata`) | 前端应用拉取指标元数据，网络中断、延迟或不可用威胁 |
| Component Consumer ↔ Normalizer | 组件或路由参数传入未预期的畸变 Key 字符串 |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
