## 1. 四梯度状态胶囊与视觉反馈 (VAL-01, VAL-02, VAL-03, GUIDE-01, GUIDE-02)

| Option | Description | Selected |
|--------|-------------|----------|
| 四梯度宽容胶囊+非破坏性保留（推荐） | 彻底移除失焦清空输入框逻辑（移除 `value = undefined`）。输入框占位符动态展示生理参考范围（GUIDE-01）。输入框下方常态化展示健康解读卡片（GUIDE-02）。输入数值动态映射为四梯度状态胶囊（正常绿色/预警橙黄/危急深橙/超限红色），仅超出生理不可能极限时禁止保存，预警偏高偏低值完全允许用户正常保存入库（VAL-02, VAL-03）。 | ✓ |
| 仅移除失焦抹除，保留纯文本错误 | 仅移除 `value = undefined`，但依然沿用 Element Plus 传统的红色错误提示文字，不引入颜色胶囊与解读卡片。 | |
| 弹窗内实时图表参考线 | 在弹窗内绘制迷你 ECharts 图表，将当前输入值标示在坐标轴上。（开发成本高，弹窗空间受限，移动端与小屏体验较差）。 | |

**User's choice:** 四梯度宽容胶囊+非破坏性保留（推荐）  
**Notes:** 彻底保障用户的录入劳动，兼顾科学性与宽容性。

## 2. 血压同屏协同与倒置对调交互 (GUIDE-03, VAL-04)

| Option | Description | Selected |
|--------|-------------|----------|
| 同屏并排网格+内联一键对调按钮（推荐） | 血压录入同屏以 2 列网格并排展示收缩压与舒张压（GUIDE-03）。当检测到 `收缩压 <= 舒张压` 倒置时，输入框下方即时呈现黄色告警条，并提供「一键对调数值」操作按钮，点击后原地瞬时互换数值并轻提示（VAL-04）。 | ✓ |
| 自动静默对调数值 | 当检测到倒置时，前端不提示用户，在失焦或提交时自动静默将两值对调。（缺乏用户知情权，可能导致用户误解）。 | |
| 仅文字报错，让用户手动重新输入 | 仅以红色文字提示“收缩压不能小于舒张压”，让用户手动重新输入两个框。（交互繁琐，未能解决误输入场景下的操作负担）。 | |

**User's choice:** 同屏并排网格+内联一键对调按钮（推荐）  
**Notes:** 用户体验最优，极大提升移动端或快速录入时的容错率。

## 3. 急危重症二次确认与就医指引 (VAL-05)

| Option | Description | Selected |
|--------|-------------|----------|
| 友好解释性模态确认窗+急救就医指引（推荐） | 当数值进入临床危急值区间（如高压≥180、低压≥110、血糖≥16.7等）时，点击保存弹出温馨的二次确认模态窗。提示防误触，提供急救或就医建议；主按钮为“返回修改”，次按钮为“确认录入无误并保存”。确认后顺利保存入库（VAL-05）。 | ✓ |
| 强阻断拒绝录入，强制用户去医院 | 一旦检测到危急值直接弹窗拦截，禁止数据入库。（违反健康监控系统真实记录异常病情的初衷，会导致关键急症数据丢失）。 | |
| 仅托盘通知提示，不弹窗确认 | 仅以 Element Plus Notification 弹出一条悬浮通知，直接保存。（缺乏防误触保护，容易因多输数字导致数据库污染）。 | |

**User's choice:** 友好解释性模态确认窗+急救就医指引（推荐）  
**Notes:** 平衡了医疗安全预警与数据真实记录双重诉求。
