## Visual Hierarchy & Anchors

### 1. Primary Visual Anchor (Focal Point)
- **预防保健页 (`prevention/Metrics.vue`) 核心焦点：** 卡片头部操作栏（Header Action Bar）中的「添加保健指标」高对比度主按钮，以及历史记录表格中的生理数值与四梯度状态胶囊。
- **生活方式仪表盘 (`wellness/Dashboard.vue`) 核心焦点：** 页面顶部的健康习惯活动环（ActivityRings）复合进度视点，以及右上角「添加生活方式数据」主操作按钮。
- **录入弹窗视图核心焦点：** 对话框内的指标数值录入控件（数值型指标 `el-input-number` / 心情指标 `el-rate`）与其紧邻展示的**四梯度状态胶囊微标签（Tier Capsule Badge）**。
- **视觉优先级流向：**
  1. **第 1 视点（输入与即时状态反馈）：** 置顶标签排版下的数值输入组件与状态胶囊。
     - 若选择心情，呈现 1-5 星级控件并实时显示中文等级说明（很差/较差/一般/较好/很好）；
     - 若选择数值型指标，占位符动态展示“参考范围: 1500 ~ 2500 ml”，用户键入数值时胶囊实时平滑过渡呈现正常（绿）、预警（橙黄）、危急（橙红）或超限（暗红）。
  2. **第 2 视点（认知引导与医学解读）：** 表单下方的常态化健康参考标准解读卡片（`ReferenceGuideCard`），弱化背景、提供生活方式标准指南与场景建议（如运动、睡眠与水分补充提示）。
  3. **第 3 视点（行为动作）：** 弹窗右下角操作按钮栏。主操作「保存保健指标 / 保存修改记录」（高饱和青绿 Accent 色填充）与次操作「取消操作」（中性幽灵按钮）形成明确主次层级。

### 2. Accessibility & Icon Fallback
- 所有图标动作均配备显式文本标签（如 `<el-button type="primary"><el-icon><Plus /></el-icon>添加保健指标</el-button>`）。
- 状态胶囊同时使用“色彩 + 矢量图标 + 语义文字”三重通道传达状态（如绿色 + 对勾图标 + “正常参考区间”；橙黄 + 感叹号图标 + “指标偏高”；橙红 + 铃铛图标 + “严重危急值”），确保色弱与色盲用户无障碍辨别。
- 心情星级打分具备完整键盘导航、悬浮预览与辅助读屏标签，选中心情等级时同步输出文本。

### Tier-Specific Badge & Guidance Copywriting for Wellness Metrics

1. **Tier 1 (Normal 正常参考区间):**
   - 胶囊文案: `正常参考区间`
   - 说明文案: `处于健康生活标准推荐区间 (${normalMin} ~ ${normalMax} ${unit})`
2. **Tier 2 (Warning 预警偏差 - 非阻塞允许保存):**
   - 偏高胶囊: `指标偏高`
   - 偏低胶囊: `指标偏低`
   - 说明文案: `指标偏${isHigh ? '高' : '低'}（标准推荐为 ${normalMin} ~ ${normalMax} ${unit}）。生活方式数据受作息与运动波动影响，可直接点击保存追踪真实习惯。`
3. **Tier 3 (Critical 急危重症预警 - 二次确认防误触):**
   - 胶囊文案: `严重危急值`
   - 说明文案: `达到严重异常预警线 (${value} ${unit})。请先核对是否误输入了额外数字，保存前需二次确认。`
   - 弹窗标题: `检测到生活方式极端危急数值`
   - 弹窗正文: `您录入的 ${displayName} 为 ${value} ${unit}，已达到重度安全预警阈值（如单日严重超量饮水可能导致水中毒，极端缺乏睡眠存在猝死风险）。如属手抖误输请返回修改；若记录属实，请注意身体安全并保持规律生活。`
4. **Tier 4 (Hard Bound 生理不可能极限 - 阻止提交并保留输入):**
   - 胶囊文案: `超出人体存活极限`
   - 说明文案: `${displayName}有效生理区间为 ${hardMin} ~ ${hardMax} ${unit}，请核对是否多输了数字。`
