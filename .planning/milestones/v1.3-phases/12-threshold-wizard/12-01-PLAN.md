<objective>
Rewrite `ThresholdRangeChecker` around a single private `classify()` and make the four public range methods delegate to it, fixing FIX-01 (the inverted warning-band condition) and satisfying FIX-05 (D-18 full boundary coverage).

Purpose: A user who configures a warning threshold must actually receive a warning. Today `isWarningRange` returns false for every value inside the warning band, so the alert engine silently returns null and the alert never fires — every later phase-12 wizard improvement is worthless until this is fixed.
Output: A `classify()`-based checker whose bands are exactly complementary to the untouched `isNormalRange`, plus the first dedicated test class for it (the class has no test today).
</objective>
