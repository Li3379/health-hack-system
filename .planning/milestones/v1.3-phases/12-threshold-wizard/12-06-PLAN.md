<objective>
Build `ThresholdZoneBar.vue`, a five-band live preview of where the four threshold boundaries sit, plus the two theme tokens it needs.

Purpose: THR-04 asks the user to see the four zones and where the current input lands. The UI-SPEC measured that the tinted bands are only 1.08-1.35:1 against their surfaces, so the design is explicitly "colour is decoration, the name + value pair is the information" — the component must honor that or it becomes unusable.
Output: A reactive, accessible, independently-tested presentation component and its colour tokens.
</objective>
