## Visual Hierarchy & Anchors

### 1. Primary Visual Anchor (Focal Point)
- **对话框核心焦点：** `QuickInputDialog` 的生理数值录入组件（`el-input-number`）与其紧邻展示的**四梯度状态胶囊徽章（Tier Capsule Badge）**。
- **视觉优先级流向：**
  1. **第 1 视点（输入与即时反馈）：** 输入框与状态胶囊。占位符呈现“参考范围: 3.9 ~ 6.1 mmol/L”，用户键入数值时胶囊实时平滑过渡呈现正常（绿）、预警（橙黄）、危急（橙红）或超限（暗红）。
  2. **第 2 视点（自纠与警示干预）：** 血压录入时若出现收缩压 <= 舒张压，输入框正下方高亮展开带黄色背景的倒置警示横幅，右侧带有醒目的「对调高低压数值」操作按钮。
  3. **第 3 视点（认知引导）：** 表单下方的常态化健康参考标准解读卡片（`ReferenceGuideCard`），弱化背景、提供医学指南背书与测量规范说明。
  4. **第 4 视点（行为动作）：** 弹窗右下角操作按钮栏。主操作「保存指标数据」（高饱和青绿 Accent 色填充）与次操作「取消录入」（中性幽灵按钮）形成明确主次层级。

### 2. Accessibility & Icon Fallback
- 所有图标动作均配备显式文本标签（如 `<el-button :icon="Switch">对调高低压数值</el-button>`）。
- 状态胶囊同时使用“色彩 + 矢量图标 + 语义文字”三重通道传达状态（如绿色 + 对勾图标 + “正常参考区间”；橙黄 + 感叹号图标 + “指标偏高”），确保色弱/色盲用户无障碍辨别。

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | 保存指标数据 |
| Cancel Action | 取消录入 |
| Secondary Action (Blood Pressure Swap) | 对调高低压数值 |
| Critical Confirmation Primary (Cancel/Review) | 返回核对修改 |
| Critical Confirmation Secondary (Proceed) | 确认录入无误并保存 |
| Empty state heading | 暂无可选健康指标 |
| Empty state body | 系统元数据字典暂未加载到可选指标项目，请检查网络连接或点击下方按钮重新同步指标定义。 |
| Error state (Tier 4 Hard Limit) | 指标数值超出人体存活极限（如心率超出 20 ~ 300 次/分），无法保存入库。请核对是否多输或误输了数字并重新输入。 |
| Error state (Blood Pressure Inverted) | 检测到收缩压（高压）低于或等于舒张压（低压），疑似输入颠倒。请点击右侧按钮一键对调。 |
| Destructive confirmation | 放弃未保存数据: 您已录入但尚未保存的指标数据将会丢失，确定要关闭录入弹窗吗？ |

### Tier-Specific Badge & Guidance Copywriting

1. **Tier 1 (Normal 正常参考区间):**
   - 胶囊文案: `正常参考区间`
   - 说明文案: `处于临床标准正常区间 (${normalMin} ~ ${normalMax} ${unit})`
2. **Tier 2 (Warning 预警偏差 - 非阻塞):**
   - 偏高胶囊: `指标偏高`
   - 偏低胶囊: `指标偏低`
   - 说明文案: `指标偏${isHigh ? '高' : '低'}（正常参考为 ${normalMin} ~ ${normalMax} ${unit}）。若受空腹/餐后或运动状态影响属于正常波动，可直接点击保存。`
3. **Tier 3 (Critical 急危重症 - 二次确认):**
   - 胶囊文案: `严重危急值`
   - 说明文案: `达到临床危急重症预警线 (${value} ${unit})。请先核对测量仪器与输入数字，保存前需二次确认。`
   - 弹窗标题: `检测到严重生理危急值`
   - 弹窗正文: `您录入的 ${displayName} 为 ${value} ${unit}，已达到重度危急预警阈值。如属误触请输入正确数值；若测量属实，请保持平静并立即遵医嘱就医或呼叫急救。`
4. **Tier 4 (Hard Bound 生理不可能极限 - 阻止提交并保留输入):**
   - 胶囊文案: `超出人体存活极限`
   - 说明文案: `${displayName}有效生理区间为 ${hardMin} ~ ${hardMax} ${unit}，请核对是否多输了数字。`

## UI Considerations

Applicable state considerations resolved: 8 covered, 0 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | QuickInput button groups / QuickInputDialog | ✅ covered | 当元数据未就绪或未匹配到指标时，展示专用空状态插槽与“暂无可选健康指标”友好文案，并提供刷新重试按钮，绝不白屏崩溃。 |
| loading | QuickInputDialog submit button & metadata fetch | ✅ covered | 提交表单时「保存指标数据」按钮进入 Element Plus `:loading="true"` 禁用态，防止快速重复连击并发入库；元数据异步拉取期间输入框展示骨架占位提示。 |
| error | Tier 4 Hard Limit & Network Submit Failure | ✅ covered | Tier 4 触发时展示明确生理极限警示文案并阻止提交，原样保留用户已输入字符；提交接口抛出 4xx/5xx 时触发 `ElMessage.error` 提示并完整保留当前对话框中已填数据，方便重试。 |
| populated | QuickInputDialog filled with valid metric | ✅ covered | 正常填报完成状态：数值输入框展示格式化数字，四梯度胶囊稳定显示绿色「正常参考区间」或橙黄色「指标偏高/偏低」，参考解读卡片完整渲染医学建议，提交按钮可用。 |
| partial | Blood Pressure Input (systolic entered, diastolic empty) | ✅ covered | 血压同屏录入时，若仅填入收缩压而舒张压为空，输入框呈现半录入引导状态；只有两个字段均填入且出现 `高压 <= 低压` 时才激活倒置警示横幅与对调动作。 |
| overflow | ReferenceGuideCard & GuideHint text | ✅ covered | 解读卡片中的临床医学指导文本（`guideHint`）采用自适应容器与 `word-break: break-word` 排版，移动端或窄屏弹窗下内容平滑垂直折行，无水平溢出或被遮挡截断。 |
| zero-one-many | QuickInput metric buttons | ✅ covered | 快捷录入入口按钮组使用弹性网格（`grid-template-columns: repeat(auto-fill, minmax(80px, 1fr))`），在 0、1 项或 23 项指标全量加载时均保持整齐网格对齐，不突兀变形。 |
| long-text | Extreme boundary error message & panic guidelines | ✅ covered | 危急值急救建议与极限超限提示文案在模态弹窗与 `ElAlert` 中均设置 `line-height: 1.5` 与规范内边距，长文本自动换行，按钮操作区固定吸底。 |
