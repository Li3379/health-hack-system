       - 引入 `useMetricValidation` 组合函数，将 `form.metricKey`、`form.value` 与 `form.diastolicValue` 传入，获取 `definition`、`diastolicDef`、`primaryEval`、`diastolicEval`、`isBloodPressure`、`isInverted`、`hasCritical`、`isSaveBlocked` 与 `swapBloodPressure`。
       - 彻底移除 `handleMetricKeyChange` 中清空 `form.value = 0` 的破坏性代码，实现输入异常时的非破坏性失焦保护（VAL-01, D-05）。输入框占位符动态展示 `参考范围: min ~ max unit`。
       - 在输入框下方渲染四梯度状态胶囊微标签（`el-tag`），根据 `primaryEval.status` 动态展示绿色/黄色/橙色状态文案（VAL-02, VAL-03, D-05）。

    3. 血压双字段协同与一键对调：
       - 当选择“血压”指标且处于新增模式 (`editingId === null`) 时，表单渲染收缩压与舒张压 12:12 并列栅格输入框（GUIDE-03, D-04, D-05）。
       - 检测到收缩压 <= 舒张压倒置时，渲染警告横幅与“对调高低压数值”按钮，点击调用 `swapBloodPressure()` 原子交换数值并重新校验（VAL-04, D-04, D-05）。
       - 在编辑模式下 (`editingId !== null`)，仅渲染当前指标单项输入框，不强制关联舒张压输入，规避历史单条收缩压记录无法独立修订的边界缺陷（Pitfall 3 规避）。
       - 血压新增提交时，分别向后端保存 `systolicBP` 与 `diastolicBP` 两笔小驼峰标准记录（D-04）。

    4. 参考卡片与危急值二次确认：
       - 在表单下方常态化引入 `ReferenceGuideCard`，绑定当前指标定义（GUIDE-02, D-05）。
       - 引入 `CriticalConfirmDialog` 二次确认弹窗。当用户提交包含 Tier 3 危急值（`hasCritical` 为 true）时，拦截默认提交并弹出确认窗；用户点击“确认录入”后仍可成功保存入库（VAL-05, D-05）。
       - 处于物理不可能极限（Tier 4，`isSaveBlocked` 为 true）时禁用确定按钮，但原样保留用户输入内容供其修改。
