## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → REST API (`GET /api/metrics/metadata`) | 未鉴权或已鉴权客户端请求元数据字典，数据越界或高频爬取威胁 |
| External Ingestion / DTO → Normalizer | 外部传入的未知或格式畸变指标 Key 穿透至内部领域逻辑 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Denial of Service | `MetricMetadataController` | medium | mitigate | 响应头设置 `Cache-Control: public, max-age=86400` 与强 `ETag`，网关与浏览器强缓存 24 小时，且底层为单例内存字典，无数据库查询开销。 |
| T-04-02 | Tampering / ReDoS | `MetricKeyNormalizer` | medium | mitigate | 别名查找使用预分配不可变哈希表（Map.ofEntries）与简单字符串清理，杜绝复杂回溯正则表达式，防止 ReDoS 攻击。 |
| T-04-03 | Information Disclosure | `MetricDefinition` | low | mitigate | 元数据仅包含通用临床医学基准参数，不携带任何用户隐私数据或服务器内部拓扑信息，公开 permitAll 访问安全无虞。 |
</threat_model>
