## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored threshold rows → rendered list and duplicate lookup | Rows may carry legacy alias keys that must be compared canonically |
| backend failure → page state vs toast | Two presentation channels that must never double-report |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-27 | Tampering | Duplicate lookup | low | mitigate | Canonical comparison means an attacker-supplied alias cannot create a second row that bypasses the 打开编辑 recovery affordance |
| T-12-28 | Information Disclosure | Error double-reporting | low | mitigate | Load failures render a state block and suppress the toast, so one failure yields one message (Phase 11 D-02) |
| T-12-29 | Denial of Service | Default-rule table source | medium | mitigate | The table reads the metadata store rather than a second hardcoded constant, so a seed change cannot leave the UI teaching stale numbers (RESEARCH §Pitfall 7) |
| T-12-30 | Elevation of Privilege | Row ownership on delete/edit | high | mitigate | The page performs no privilege decisions; the backend re-derives ownership from the token, and the page only passes row ids the server already returned for this user (ASVS V4) |
| T-12-SC | Tampering | npm/pip/cargo installs | high | mitigate | No npm installs; `@vueuse/core` must not be imported directly (REQUIREMENTS §Out of Scope) |
</threat_model>
