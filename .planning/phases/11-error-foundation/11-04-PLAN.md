       `export function showError(raw: unknown, fallbackKey: string, opts?: { retry?: () => void | Promise<void>; action?: { label: string; onClick: () => void }; silent?: boolean }): ApiError`
       - 第一行 `const err = normalizeApiError(raw)`。
       - 早退三分支，全部 `return err` 且**不调用 ElMessage**：`err.kind === 'cancel'`；`err.kind === 'validation'`；`opts?.silent === true`。
       - `const message = resolveMessage(fallbackKey, err.message)`。
       - **截断规则（关键，别做错方向）**：只有当 `resolveMessage` 返回的是**字典回退文案**（即 `err.message` 为空或全是空白）时才应用 30 字上限 —— 字典条文本身就必须 ≤ 30 字，由 `errorMessages.spec.ts` 断言保证，因此这一分支实际不会触发截断。当返回的是**后端 message**时（`err.message` 非空），**原样使用、绝不 slice**：后端中文消息可能超过 30 字，UI-SPEC 的 long-text 兜底要求是「换行而非省略号」，截断会丢语义。统一用变量名 `shown` 承载最终文本。
       - 分支 A（`err.kind === 'auth'`）：**不在此处产生 toast** —— 401 的提示由 `logout()` 承担（见 11-03），此处直接 `return err`，避免令牌过期出现两条消息。在函数内用注释写明这一归属。
       - 分支 B（`err.kind === 'business'` 且无 `opts.retry` 且无 `opts.action`）：`ElMessage({ type: 'error', message: shown, grouping: true, duration: 4000, showClose: true })`。
       - 分支 C（`opts.retry` 存在，或 `err.kind === 'network' || err.kind === 'server'`，或 `opts.action` 存在）：
         - 导出 `export const ERROR_CODE_ACTIONS: Record<string, string> = { 'resource.exists': '打开编辑' }`（D-08 的唯一本阶段样本）。当 `err.code === 'resource.exists'` 时，若调用方**同时**传了 `opts.action` 则用其 `label` 与 `onClick`；若只传了 `onClick` 没传 label，用 `ERROR_CODE_ACTIONS[err.code]` 补标签。**若调用方完全没提供 onClick，则不渲染动作按钮** —— 只显示文字 toast，绝不渲染点击无反应的死按钮。
         - 用 `h('div', { class: 'error-toast' }, [...])` 构造：`h('span', { class: 'error-toast__text' }, shown)` + 动作控件。有 retry 时动作是 `h('button', { type: 'button', class: 'error-toast__retry', 'aria-label': `重试：${shown}`, onClick: handleRetry }, '重试')`；有 action 时是同样结构但 `aria-label` 为 `action.label`、类名 `error-toast__action`、文本为 `action.label`。
         - `handleRetry`：先 `handler.close()` 关闭本条消息，再 `Promise.resolve(opts.retry!()).catch(() => {})` —— **绝不自动重试**，只执行调用方回调一次（D-03）。
         - `const handler = ElMessage({ type: 'error', message: vnode, grouping: false, duration: 0, showClose: true })`。注意 `handler` 需在 `handleRetry` 之前声明或用 `let handler: MessageHandler` 提前声明，避免 TDZ。
       - 模块级去重闩锁：`const recent = new Map<string, number>()`；key 为 `${shown}|${opts.retry ? 'retry' : opts.action?.label ?? ''}`；`Date.now() - (recent.get(key) ?? 0) < 2000` 时直接 `return err` 不弹；否则写入当前时间戳。**只对 VNode 分支生效**（字符串分支交给 EP 的 grouping）。
       - 最多可见 3 条：模块级 `const openHandlers: MessageHandler[] = []`，每次新建后 push，超过 3 条时 `openHandlers.shift()?.close()`；`handler.close` 包装以从数组移除。
       - 本文件是本阶段唯一 import `ElMessage` 的 `utils/` 模块。**允许** import `normalizeApiError`、`resolveMessage`、`h`（来自 vue）。
       - 样式类名固定为 `error-toast` / `error-toast__text` / `error-toast__retry` / `error-toast__action`（Task 2 在 theme.css 落地）。
