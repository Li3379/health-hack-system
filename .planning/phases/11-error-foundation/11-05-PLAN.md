    `export interface SummaryItem { field: string; label: string; message: string }`

    `export function useFormServerErrors(options: { fieldOrder?: string[] } = {})` 返回：
    - `fieldErrors: Ref<Record<string, string>>` —— 初始 `{}`
    - `summaryItems: ComputedRef<SummaryItem[]>` —— 由 `Object.entries(fieldErrors.value)` 映射为 `{ field, message, label: fieldLabel(field) }`，排序规则：若 `options.fieldOrder` 提供，按 `fieldOrder.indexOf(field)` 升序（未命中的排末尾，保持相对顺序）；否则保持 `Object.entries` 的插入顺序（即后端顺序）。
    - `apply(err: ApiError): void` —— **仅当 `err.kind === 'validation'` 时动作**，其他 kind 直接 return（呈现权在 showError）。取值时先 `const next = { ...err.fieldErrors }`；若 `err.formField` 存在且 `next.value` 存在，则 `next[err.formField] = next.value; delete next.value`（血压双请求把后端通用 `value` 改投到 `diastolicValue`）。赋值 `fieldErrors.value = next`。**不在此处清空用户输入、不调用任何表单 reset。**
    - `clearField(field: string): void` —— 浅拷贝删除该 key 后重新赋值（触发响应式）。
    - `reset(): void` —— `fieldErrors.value = {}`。
    - `focusField(field: string): void` —— `document.querySelector<HTMLElement>('[data-field="' + field + '"]')`，再在其中 `querySelector<HTMLElement>('input, textarea, .el-select__wrapper, .el-rate')`，若命中则 `focus()` 与 `scrollIntoView({ block: 'center' })`。全部为原生 API，**不引入 GSAP**。
    - 不返回 `summaryRef`（焦点由组件持有，见 Task 2），不 import 任何 store，不 import ElMessage。
